# 3. 无重复字符的最长子串

---

## 题目

给定一个字符串`s`，请你找出其中不含有重复字符的`最长子串`的长度。

## 示例

- 示例1:

    - 输入: s = "abcabcbb"
    - 输出: 3
    - 解释: 因为 "abc" 是最长的不重复字符子串，所以返回 3 。

- 示例2:

    - 输入: s = "bbbbb"
    - 输出: 1
    - 解释: 因为 "b" 是最长的不重复字符子串，所以返回 1 。

- 示例3:

    - 输入: s = "pwwkew"
    - 输出: 3
    - 解释: 因为 "wke" 是最长的不重复字符子串，所以返回 3 。

## 提示

- 1 <= s.length <= 10^9
- s[i] 为 ASCII 码可见字符

## 解题

### 方法一: 滑动窗口

思路及算法:
> 使用滑动窗口，窗口内不包含重复字符，窗口右边界向右移动，如果遇到重复字符，则窗口左边界向右移动，直到窗口内不包含重复字符。

[代码:](../algorithm/src/com/cc/a003/Solution.java)
```java
public class Solution {
  public int lengthOfLongestSubstring(String s) {
    // 哈希集合，记录当前窗口中的字符
    HashSet<Character> hashSet = new HashSet<>();
    // 获取字符串的长度
    int length = s.length();
    // 记录窗口的边界，left为左边界
    int left = 0;
    // 记录最长子串的长度
    int maxLength = 0;
    // 遍历字符串时的i为右边界
    for (int i = 0; i < length; i++) {
      // 第一个字符时，直接加入窗口，此时左边界为0，右边界为0
      if (i == 0) {
        hashSet.add(s.charAt(i));
        maxLength = 1;
        continue;
      }
      // 从第二个字符开始，判断是否与窗口中的字符重复
      while (hashSet.contains(s.charAt(i))) {
        // 如果重复，则左边界向右移动，直到不重复
        hashSet.remove(s.charAt(left));
        left++;
      }
      // 此时窗口中不包含重复字符，加入窗口
      hashSet.add(s.charAt(i));
      // 更新最长子串的长度
      maxLength = Math.max(maxLength, i - left + 1);
    }
    return maxLength;
  }
}

```

- 时间复杂度：O(n)
- 空间复杂度：O(1)，因为哈希集合中最多包含 128 个字符

### 方法二: 优化方法一

思路及算法:
> 方法一中，窗口左边界向右移动时，每次只移动一个位置，而方法二中，窗口左边界向右移动时，移动到重复字符的位置。

[代码:](../algorithm/src/com/cc/a003/Solution2.java)
```java
public class Solution2 {
  public int lengthOfLongestSubstring(String s) {
    // 定义hashmap记录字符和对应的索引
    HashMap<Character, Integer> hashMap = new HashMap<>();
    // 字符串的长度
    int length = s.length();
    // 记录当前无重复字符的子串的长度
    int maxLength = 0;
    // 记录窗口的左边界left
    int left = 0;
    // 遍历字符串
    for (int i = 0; i < length; i++) {
      char c = s.charAt(i);
      // 如果字符在hashmap中存在，则更新左边界
      if (hashMap.containsKey(c)) {
        // 更新左边界为重复字符的下一个位置和当前左边界中的较大值
        left = Math.max(left, hashMap.get(c) + 1);
      }
      // 将字符和对应的索引存入hashmap
      hashMap.put(c, i);
      // 更新当前无重复字符的子串的长度
      maxLength = Math.max(maxLength, i - left + 1);
    }
    return maxLength;
  }
}

```

- 时间复杂度：O(n)
- 空间复杂度：O(1)，因为哈希集合中最多包含 128 个字符

### 方法三: 优化方法二

思路及算法:

> 方法二中，需要创建一个哈希表来记录字符和对应的索引，空间复杂度为O(1)。方法三中，我们可以通过使用数组来代替哈希表，将空间复杂度优化为O(1)。

[代码:](../algorithm/src/com/cc/a003/Solution3.java)
```java
public class Solution3 {
  public int lengthOfLongestSubstring(String s) {
    // 定义一个数组来记录字符的索引
    int[] charIndex = new int[128];

    int maxLength = 0;
    int left = 0;
    for (int i = 0; i < s.length(); i++) {
      char c = s.charAt(i);
      // 如果字符在当前子字符串中，则更新左边界
      if (charIndex[c] >= left) {
        left = charIndex[c];
      }
      charIndex[c] = i + 1;
      maxLength = Math.max(maxLength, i - left + 1);
    }
    return maxLength;
  }
}


```

- 时间复杂度：O(n)
- 空间复杂度：O(1)，因为哈希集合中最多包含 128 个字符
