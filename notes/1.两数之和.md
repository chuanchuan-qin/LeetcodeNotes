# 1. 两数之和

---

## 题目

给定一个整数数组`nums`和一个整数目标值`target`，请你在该数组中找出**和为目标值**`target` 的那**两个**整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。

## 示例

- 示例1:

    - 输入: nums = [2,7,11,15], target = 9
    - 输出: [0,1]
    - 解释: 因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。

- 示例2:

    - 输入: nums = [3,2,4], target = 6
    - 输出: [1,2]
    - 解释: 因为 nums[1] + nums[2] == 6 ，返回 [1, 2] 。

- 示例3:

    - 输入: nums = [3,3], target = 6
    - 输出: [0,1]
    - 解释: 因为 nums[0] + nums[1] == 6 ，返回 [0, 1] 。

## 提示

- 1 <= nums.length <= 10^9
- -10^9 <= nums[i] <= 10^9
- -10^9 <= target <= 10^9
- 只会存在一个有效答案

## 解题

### 方法一: 暴力枚举法

思路及算法:
> 两层循环，外层循环遍历数组每一个元素`x1`，内层循环从外层循环的下一个元素`x2`开始遍历，判断两数之和是否等于目标值`target`。

[代码:](../algorithm/src/com/cc/a001/Solution.java) 
```java
public class Solution {
  public static int[] twoSum(int[] nums, int target) {
    // 外部循环：遍历数组每一个元素
    for (int i = 0; i < nums.length; i++) {
      // 内部循环：从外层循环的下一个元素开始遍历
      for (int j = i + 1; j < nums.length; j++) {
        // 判断两数之和是否等于目标值target
        if (nums[i] + nums[j] == target) {
          // 返回结果
          return new int[]{i, j};
        }
      }
    }
    // 如果没有找到，则返回空数组
    return new int[]{};
  }
}
```

- 时间复杂度：O(n^2)
- 空间复杂度：O(1)

### 方法二: 利用哈希表 

思路及算法: 
> 遍历数组每一个元素`x`，判断`target - x`是否在哈希表中，如果在则返回`target - x`的下标和当前元素的下标，
> 如果不在则将当前元素`x`和下标`i`存入哈希表。

[代码:](../algorithm/src/com/cc/a001/Solution2.java)
```java
public class Solution2 {
  public static int[] twoSum(int[] nums, int target) {
    // 创建一个哈希表，用于存储数组元素和其对应的下标
    HashMap<Integer, Integer> map = new HashMap<>();
    // 遍历数组，i为当前元素的下标
    for (int i = 0; i < nums.length; i++) {
      // 判断哈希表中是否存在目标值与当前元素的差
      if (map.containsKey(target - nums[i])) {
        return new int[]{map.get(target - nums[i]), i};
      }
      // 如果不存在，则将当前元素和其下标存入哈希表
      map.put(nums[i], i);
    }
    // 如果没有找到，则返回空数组
    return new int[]{};
  }
}
```
- 时间复杂度：O(n)
- 空间复杂度：O(n)
